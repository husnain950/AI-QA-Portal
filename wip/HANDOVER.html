What to do differently

Never edit packages/ mid-conversion Each child imports the parser when it starts, so an edit gives early documents the old code and later ones the new. A mixed-revision corpus looks normal. Done twice in one session
Clear __pycache__ after mutate-and-restore The source is right while the module in memory is the version you rejected. A re-conversion had already run against it
Measure invariant and parser separately Nearly every class is part wrong-invariant, part real defect. 45 hits were all an attribute, concealing a 473-footnote defect
Know which corpus you measured Measurements use output/*.json plain_text — not what the parser sees. 42 53 [202B. vs 42 53[202B. is the difference between matching and missing
Verify a lock by removing the fix A parenting lock passed with the fix stubbed out; its two-chapter fixture let a later pass repair the damage
Report fixes that scored zero Round 4's acts lane and round 6's PART fix were both correct and moved nothing. Folding them into a total misattributes the rounds that did
A cached artifact cannot tell you its generator is wrong. Three instances this phase — and only the exemptions/ format reported itself stale, unprompted. That is the argument for the register snapshot.
