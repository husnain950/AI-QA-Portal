calibrate finds no running header here — running_header='', header_keys=[] — so the band falls back to page_h * 0.055, and _is_header_line dropped everything above it.

That function exists for exactly this. Its docstring is ledger P37, where Federal Excise 01.07.2017's whole THIRD SCHEDULE title block was discarded and its content appended to the SECOND SCHEDULE, and it states the principle plainly — "deciding what a line is from where it sits instead of from what it says." But its guard only applied where a header had been detected: 

    keys = getattr(cal, "header_keys", ()) or ()
    if not keys:
        return True                       # no header detected: positional band

The 5.5% band is conservative about keeping headers out, and the exact opposite about keeping law in. This document prints no header, so the top of a page is simply where the next rule begins.

The fix Shorter than what it replaces.

Drop what repeats; keep what does not

    if ln.top >= cal.header_max_top:
        return False
    txt = ln.text().strip()
    if not txt or not any(c.isalpha() for c in txt):
        return True                       # blank, or a bare folio
    return _FOLIO_RE.sub("#", txt) in (getattr(cal, "header_keys", ()) or ())

For a document with a detected header this is the same decision, byte for byte. What changes is that "no keys" now means keep the text — and calibrate fills header_keys from recurrence when nothing clears its 40% threshold.
